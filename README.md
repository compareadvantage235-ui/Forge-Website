# Forge Wellness & Recovery — Astro + Tailwind Website

## Tech stack
- **Astro 4** — static site generator, zero JS by default
- **Tailwind CSS 3** — utility-first CSS
- **Unsplash** — real photography (no placeholder images)
- **Lucide / inline SVG** — premium icons

## Run locally
```bash
npm install
npm run dev        # http://localhost:4321
npm run build      # builds to dist/
```

## Deploy to Netlify via GitHub (recommended)
1. Push this folder to a GitHub repository
2. In Netlify: **Add new site → Import from Git**
3. Build command: `npm run build`
4. Publish directory: `dist`
5. Netlify auto-builds on every push

## Deploy to Netlify Drop (manual)
1. `npm install && npm run build`
2. Drag the `dist/` folder into Netlify Drop
